数据综合分析评估平台 · 离线独立演示
==================================================

启动方式
  1. 双击本目录下的 index.html，即可在浏览器中打开控制台；
  2. 顶部「综合分析」进入分析页（analysis.html）。

说明
  · 无需安装任何软件、运行时或后端服务，也不需要联网；
  · 所有脚本、样式、示例图片均已放在本目录内，页面通过相对路径引用；
  · 采集、清洗、AI 翻译、标签公式、设置保存等操作均由本地模拟数据应答，
    可完整演示页面交互、图表与任务进度；
  · 内置 2 张示例插画（assets/sample-01.jpg、sample-02.jpg）与配套作品样例：
    在「原神」数据集第 1 页前 3 个作品（月下少女 / 樱下剑客 / 星月与花道）中可查看，
    小红书页的前 2 条笔记也带有同样的示例媒体；
  · 示例数据为演示用途，不代表真实统计结果。

目录
  index.html      控制台入口（推荐从这里开始）
  analysis.html   综合分析入口
  js/             打包脚本与离线数据层
  css/            样式表
  vendor/         axios、ECharts（本地文件）
  assets/         示例图片

推荐浏览器：Chrome / Edge / Firefox 最新版本。
